# TRIP:ON v0.13

이번 업데이트는 기능 추가보다 **모바일 화면의 일관된 디자인 정리**를 우선하면서, 지난 여행을 복원하기 위한 Timeline 기능과 이미지 호환성을 함께 보강한 버전입니다.

## 핵심 변경

- 일정 추가 시 폼 간격, 2열 시간/시간대, 장소 선택 카드 정렬을 전면 정리했습니다.
- Google Timeline에서 확인된 **방문 장소만** DAY별 일정으로 가져올 수 있습니다. 이동 구간은 자동 일정으로 만들지 않습니다.
- 이미 같은 날 같은 장소가 일정에 있으면 새 일정을 중복 생성하지 않고 기존 일정에 완료 기록을 연결합니다.
- Timeline 자동 일정은 `import_source / import_source_ref`로 중복 생성을 방지합니다.
- 커버/기록/영수증/예약 첨부 이미지에서 HEIC/HEIF를 공통 유틸로 JPEG 변환합니다.
- 과거에 저장된 HEIC 커버와 기록 이미지는 가능한 경우 브라우저에서 JPEG 미리보기로 변환합니다.
- 예약 종류에 따라 항공/기차/버스/숙소/식당/입장권/렌터카/기타 아이콘이 달라집니다.
- 홈/여행/스크랩/MY와 여행 상세 탭에 약 210ms의 은은한 slide-up + fade 전환 효과를 추가했습니다.
- 국내/해외 장소의 검색 출처와 상관없이 좌표가 저장된 장소는 하나의 여행 지도에 함께 표시됩니다. 지도 화면 자체는 국내 좌표만 있으면 Kakao Map, 그 외에는 Google Maps를 우선합니다.

## API 호출 원칙

- 장소 검색은 검색 버튼을 눌렀을 때만 요청합니다.
- 여행 지도를 열 때는 저장된 좌표를 사용하며 장소 검색 API를 다시 호출하지 않습니다.
- Timeline은 좌표가 없는 고유 Google Place ID만 최초 한 번 확인하고 이후 저장된 장소를 재사용합니다.
