# TRIP:ON v0.15.4

v0.14.2 이후 누적 WIP를 한 번에 정리한 적용 버전입니다.

## 누적 기능

### v0.14.3
- 정확한 날짜 / 월까지 / 연도만 / 미정 여행 지원
- 기간만으로 DAY 1..N 작성 가능
- 여행 복제: 기본정보, DAY 구조, 준비 목록, 선택적 일정 초안 복사

### v0.14.4
- 빠른 기록: 사진 / 메모 / 지출
- Android/PWA 공유 → TRIP:ON 스크랩

### v0.14.5
- 장소 스크랩을 특정 DAY의 `일정 후보`로 보관
- 후보를 시간 미정 일정으로 승격 가능

### v0.14.6
- 오프라인 여행함
- 일정·예약·준비·기록과 선택한 첨부파일을 IndexedDB에 저장
- 설치형 PWA 오프라인 셸 지원

### v0.14.7
- 국내여행 / 해외여행 기본 준비 템플릿
- 현재 체크리스트를 개인 템플릿으로 저장·불러오기·삭제

### v0.14.8
- DAY별 계획/실제 이동 요약
- 이동시간, 이동거리, 이동수단별 합계

### v0.14.9
- 여행 일정/예약 `.ics` 캘린더 내보내기
- 시간 미정 일정은 하루 종일 일정으로 처리

### v0.15.0
- DAY 자동 회고 초안
- 일정, 실제 방문, 기록, 사진, 지출, Timeline을 바탕으로 초안 생성 후 직접 수정·저장

### v0.15.1
- 사진 지도
- 장소별 사진 묶음, DAY 필터, 위치 미연결 사진 관리
- 기록에 여행 장소 연결 가능

### v0.15.2
- 여행 통계 확장
- 실제 이동거리/시간, 방문 장소/도시, 이동수단, 체류시간, 지출 비율, DAY별 요약

### v0.15.3
- 오프라인 여행 자동 동기화
- 새/삭제 첨부만 증분 갱신
- 여행 목록에서 오프라인 상태·마지막 동기화 시각 표시 및 바로 저장
- Wi-Fi에서만 첨부 자동 업데이트 옵션

### v0.15.4
- 공동여행 확장
- 스크랩 `가고 싶어요`
- 일정 `가자 / 보류 / 패스` 투표
- 준비물·할 일 담당자 지정
- owner/editor 참여, viewer 조회 전용
- 공유 이탈 시 개인 반응 자동 정리

## DB
v0.14.3~v0.15.4에 필요한 DB migration은 현재 사용 중인 Supabase 프로젝트에 이미 적용되어 있습니다.
이 릴리스의 `supabase/` 파일은 신규 환경 복구 및 이력 보관용입니다.

## 백업
데이터 백업 포맷은 v7이며 기존 v1~v6 복원을 계속 지원합니다.

## 검증
- JS/JSX syntax transpile
- 상대경로 import 검사
- CSS parse 검사
- service worker syntax 검사
- DB RLS/Realtime 주요 권한 테스트

실기기에서 확인이 필요한 항목: Android Share Target, 설치형 PWA 완전 오프라인 재실행, 네트워크 복구 자동 동기화/Wi-Fi 판별, 캘린더 앱 import UX.
