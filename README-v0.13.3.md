# TRIP:ON v0.13.3

이번 버전은 일정 연결/수정 흐름과 루트 헤더 정렬을 다듬는 패치입니다.

## 변경사항
- 예정 ↔ 실제 연결 후보를 현재 DAY가 아니라 여행 전체 일정에서 불러옵니다.
- 연결 후보를 DAY → 시간순으로 정렬하고, 각 후보에 DAY/시간을 함께 표시합니다.
- Timeline 실제 방문 상세에서 `실제 수정` / `실제 기록 수정` 버튼을 명확하게 노출합니다.
- 예약의 `일정 연결` 선택창을 DAY → 시간순으로 정렬합니다. 시간 미정 일정은 같은 DAY의 시간 있는 일정 뒤에 표시됩니다.
- 예약 일정 선택 옵션을 `DAY 2 · 17:00 · 일정명` 형식으로 표시합니다.
- 홈 우측 상단의 기능 없는 Sparkles 버튼을 제거했습니다.
- 홈의 TRIP:ON 로고 기준선을 여행/스크랩/MY 탭과 맞췄고, 홈 전용 여백은 로고 아래 콘텐츠에서 처리합니다.
- 기존 Timeline 방문 묶음, 계획/실제 시간 표시, 페이지 전환효과는 유지합니다.

## DB
이번 버전은 새 DB 마이그레이션이 없습니다. v0.13.2까지의 마이그레이션이 적용되어 있으면 됩니다.
