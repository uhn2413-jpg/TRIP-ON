# TRIP:ON v0.12

v0.11.5 기능을 유지하면서 전체 UI 규격을 한 번 정리하고, 커버 사진의 HEIC/HEIF 문제를 보완한 버전입니다.

## 핵심 변경
- HEIC/HEIF 커버 사진을 선택하면 브라우저에서 JPG로 자동 변환 후 업로드합니다.
- 기존 JPG/PNG/WebP는 변환 없이 그대로 업로드합니다.
- 커버 사진 선택 버튼의 아이콘/문구가 겹치지 않도록 레이아웃을 정리했습니다.
- 커버 사진 섹션, 색상 선택, 버튼, 입력창, 바텀시트의 규격을 정리했습니다.
- 제목/본문/라벨/보조문구의 크기와 굵기 차이를 완화해 화면별 타이포그래피를 통일했습니다.
- 일정/여행 상세/홈/설정 카드의 테두리, 반경, 간격을 같은 디자인 시스템으로 맞췄습니다.
- 별점은 기존 드래그 방식과 0.5 단위를 유지하고 TRIP:ON의 차분한 코랄 계열 색상을 사용합니다.
- 삭제/저장 안내 토스트는 v0.11.5와 동일하게 3초 후 자동으로 사라집니다.
- 이동 일정의 출발지/도착지, 시간+분 입력, 앞뒤 장소 자동 제안 기능은 그대로 유지합니다.

## HEIC 안내
이미 v0.11.5에서 HEIC 파일을 올린 경우 DB/Storage에는 원본이 저장되어 있지만 웹 브라우저가 해당 파일을 직접 표시하지 못할 수 있습니다.
v0.12 배포 후 같은 사진을 `사진 바꾸기`에서 한 번 다시 선택하면 JPG로 변환되어 정상 표시됩니다.
