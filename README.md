# TRIP:ON v0.14.0

`v0.13.12` 이후 변경을 한 번에 포함한 누적 업데이트입니다.

## v0.13.13에서 누적된 안정화
- DAY 메모 저장 버튼 다크모드 대비 수정
- 일정 탭에 `오늘의 숙소` 표시 (`오늘 체크인 / 숙박 중 / 오늘 체크아웃`)
- 국내 장소는 카카오맵, 해외 장소는 Google Maps로 외부 지도 연결
- 지도 provider 초기화 안정화
- Google Timeline 대용량 ZIP/JSON 처리 시 반복 정규화와 메모리 사용 감소

## 완전 백업
- 기존 JSON 데이터 백업 유지
- `첨부파일 포함 ZIP` 백업 추가
- ZIP 내부에 `backup.json` + 여행 커버/기록 사진·티켓·영수증/예약 이미지·PDF 원본 포함
- 복원 시 Storage 파일 재업로드 + DB 경로 재연결
- 공유받은 남의 여행은 내 백업에 섞지 않고, 내가 소유한 여행에 공동편집자가 추가한 데이터/첨부는 포함
- 앱 환경설정도 백업/복원

## 여행 공유 · 실시간 공동편집
- 여행 상세 상단에 `공유` 메뉴 추가
- 초대 링크 권한: `편집 가능` / `보기만`
- 링크를 받은 사용자는 로그인 후 자동 참여하고 해당 여행으로 이동
- 공유 여행은 여행 목록에 `공유 · 편집` 또는 `공유 · 보기` 배지 표시
- 편집 가능 멤버는 일정/준비/기록/지출 등을 공동 수정
- 보기만 멤버는 수정 UI가 숨겨지고 실시간 변경만 확인
- 소유자는 참여자의 권한 변경/내보내기 가능
- 참여자는 스스로 공유 여행에서 나가기 가능
- Supabase Realtime으로 열린 여행의 변경사항 자동 새로고침
- 공유 여행의 사진/PDF도 권한에 맞게 Storage 접근
- 공유 편집자가 소유자의 개인 장소 원본을 수정하지 않도록 장소 소유권 보호

## DB
공유 기능용 Supabase migration이 포함되어 있습니다. 현재 연결된 Supabase 프로젝트에는 이미 적용된 상태입니다.

## 검증
- JS/JSX 28개 syntax transpile: 오류 0
- 상대경로 import 누락: 0
- CSS parser 오류: 0
- Owner / Viewer / Editor RLS 역할 테스트 통과
- Viewer: 여행 조회 가능, 수정 불가
- Editor: 여행 수정 가능
- Editor: 소유자 장소 조회 가능, 원본 장소 수정 불가
- 현재 Storage 파일 3개와 완전백업 참조 3개 일치
