# TRIP:ON v0.15.4

개인 여행 계획·기록·아카이브 웹앱 TRIP:ON의 v0.15.4 누적 릴리스입니다.

현재 릴리스는 v0.14.2 이후 개발한 기능을 한 번에 포함합니다. 자세한 누적 변경사항은 `README-v0.15.4.md`, 실제 적용 방법은 `APPLY-v0.14.2-to-v0.15.4.md`를 확인하세요.

## 주요 기능
- 유연한 여행 날짜 및 여행 복제
- Scrap → DAY 일정 후보
- 빠른 기록 및 Android/PWA 공유 받기
- 오프라인 여행함 및 자동 동기화
- 준비물 템플릿
- 이동 요약 및 캘린더 내보내기
- DAY 회고, 사진 지도, 여행 통계
- 여행 공유, 스크랩 희망 표시, 일정 투표, 준비 담당자
- JSON/ZIP 백업 및 복원

## DB
현재 운영 중인 Supabase에는 v0.15.4까지 필요한 migration이 적용되어 있습니다. `supabase/`는 복구/이력용입니다.
