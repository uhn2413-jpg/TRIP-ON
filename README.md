# TRIP:ON v0.1

여행 전 준비 → 여행 중 기록 → 여행 후 아카이브를 한 흐름으로 관리하는 개인 여행 웹앱의 1차 UI 프로토타입입니다.

## 현재 구현
- 하단 탭: 홈 / 여행 / 스크랩 / MY
- 새 여행 만들기 3단계
  - 여행 이름 / 복수 여행지 / 날짜 또는 날짜 미정
  - 동행인
  - 기본 커버 / 한줄 설명
- 여행 상태 자동 분류
  - 날짜 미정 / 준비 중 / 여행 중 / 지난 여행
- 여행 상세 5개 탭
  - 개요 / 일정 / 준비 / 기록 / 지출
- 여행 데이터는 현재 브라우저 localStorage에 저장

## 실행
```bash
npm install
npm run dev
```
