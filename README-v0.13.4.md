# TRIP:ON v0.13.4

일정 상세/실제 기록 편집 흐름과 일정 카드 사용성을 다듬은 패치입니다.

## 변경사항

### 1. 실제 기록 수정 / 예정↔실제 연결 시트 전환 수정
- 실제 방문 상세에서 `실제 수정`, `실제 기록 수정`을 눌렀을 때 편집 시트가 정상적으로 열리도록 바텀시트 히스토리 처리를 수정했습니다.
- `예정 일정 연결`, `실제 기록 연결`도 같은 방식으로 정상 전환됩니다.
- 실제 기록 편집은 예정 시작 시간이 없어도 저장할 수 있습니다.
- Timeline 실제 기록 제목을 수정하면 일정 카드와 상세 화면에서 수정된 제목을 우선 표시합니다. 원본 장소 주소/좌표는 유지합니다.

### 2. 상세 시트 뒤 배경 클릭 관통 차단
- 상세/편집/연결 시트가 열린 상태에서 뒤 일정 카드를 눌러도 뒤 카드가 열리지 않습니다.
- 어두운 배경을 탭하면 현재 시트만 닫히며, 같은 터치가 뒤 요소로 전달되지 않도록 변경했습니다.

### 3. 이동 일정에 기존 장소 선택 추가
- 이동 일정의 출발지/도착지에서 지도 검색 외에 `등록된 장소에서 선택`을 사용할 수 있습니다.
- 여행 전체의 기존 장소를 DAY → 시간/현재 일정 순서로 나열합니다.
- 선택한 기존 장소의 저장된 주소·좌표·시간대를 재사용합니다.
- 기존 일정에서 사용자가 붙인 일정명이 있으면 이동 일정 자동 제목에도 해당 표시명을 활용합니다.

### 4. 방문 묶음 펼치기
- `3곳`, `7곳` 같은 방문 묶음 배지를 눌러 묶인 방문지를 카드 안에서 세로 목록으로 펼칠 수 있습니다.
- 펼친 목록은 실제 방문 시간 순서를 유지하고 기존 한 줄 요약보다 큰 글씨로 표시합니다.
- 다시 접을 수 있습니다.

### 5. 시간 미정 일정 상태 표시
- 시간 미정 영역의 카드에도 `예정`, `완료`, `미방문`, `취소` 상태 배지를 표시합니다.
- 시간 있는 일정과 시간 미정 일정의 상태 표현이 동일해졌습니다.
