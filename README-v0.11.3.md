# TRIP:ON v0.11.3

이번 패치는 데이터 관리 편의 수정입니다.

## 1. 로컬 여행 중복 가져오기 방지
- 로그인 전 localStorage에 남아 있는 여행과 Supabase 여행을 `여행 이름 + 시작일 + 종료일 + 여행지` 기준으로 비교합니다.
- 이미 Supabase에 같은 여행이 있으면 MY 화면의 `로컬 여행 N개 가져오기` 개수에서 제외됩니다.
- 가져오기 실행 시 이미 있는 항목은 건너뜁니다.
- 새 로컬 여행을 정상적으로 모두 가져오면 기존 localStorage 백업 키(v0.1~v0.4)를 정리합니다.

## 2. 여행 삭제
- 여행 상세 우측 상단 `…` → 여행 수정 → 마지막 단계 아래에 `이 여행 삭제` 버튼을 추가했습니다.
- 삭제 전 확인창이 뜹니다.
- 삭제하면 연결된 일정, 예약, 준비, 기록, 지출, Timeline 데이터 등은 DB의 CASCADE 규칙으로 함께 삭제됩니다.
- 기록 사진/PDF와 예약 첨부 파일은 `trip-on-files` Storage에서도 먼저 삭제합니다.
- 삭제 완료 후 `여행` 목록으로 이동합니다.
