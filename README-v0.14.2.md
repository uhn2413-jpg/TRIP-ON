# TRIP:ON v0.14.2

현재 실제 적용본 `v0.14.0`에서 바로 올릴 수 있도록 `v0.14.1`과 `v0.14.2` 수정분을 함께 포함한 누적 업데이트입니다.

## v0.14.1 누적 수정
- 모바일 일정 상단 액션을 `일정 추가` 1줄 + `오늘 동선 / 방문 묶음` 2분할 구조로 통일
- `오늘의 숙소` 영역 위·아래 간격 보정
- 공유 링크로 Google 로그인 직후 초대 수락이 세션 준비와 경합하지 않도록 순서 안정화
- 초대 수락 중에는 기술적인 실패 문구 대신 `공유 여행에 연결 중이에요` 상태 표시
- OAuth 복귀 URL에 공유 토큰 유지 + 일시 오류 자동 재시도

## v0.14.2 전환효과 구조 개선
- 모바일/태블릿의 상단 `TRIP:ON` 로고를 탭별 화면 내부에서 앱 공통 헤더로 이동
- 홈 / 여행 / 스크랩 / MY 전환 시 로고는 제자리에 유지되고, 로고 아래 본문만 페이지 전환 애니메이션 적용
- MY의 환경설정·데이터/백업 하위 화면에서도 공통 로고는 움직이지 않음
- 일정·기록 탭은 비동기 데이터 로딩 시 두 번 들썩이는 느낌을 줄이기 위해 이동 거리를 5px로 축소하고 페이드를 부드럽게 조정
- 데스크톱은 기존 상단 글로벌 네비게이션의 `TRIP:ON` 로고를 그대로 사용하고 중복 로고를 숨김
