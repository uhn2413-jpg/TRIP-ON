# TRIP:ON v0.13.12

다크모드 누락 화면을 마무리하고, 스크랩 필터 위계와 데이터 백업을 정리한 QA 업데이트입니다.

## 주요 변경
- 실제 동선/Timeline, 방문 묶음, 공동 정산 등 깊은 화면까지 다크모드 표면색·글자 대비 보완
- 일정 묶음 카드의 라이트 그라데이션이 다크모드를 덮어쓰던 우선순위 문제 수정
- 스크랩 필터 순서를 `형식(전체/장소/링크/메모) → 태그 → 여행`으로 변경
- JSON 백업 형식 v2: 테마·지도 기본값·페이지 전환 설정도 함께 보관
- 기존 v1 JSON 백업도 계속 복원 가능
- 백업 완료/복원 후 여행·일정·스크랩·기록 개수 요약 표시
- Supabase의 현재 TRIP:ON 19개 테이블과 백업 목록/외래키 복원 순서 재검증

## DB 변경
없음. v0.13.10 스크랩 태그 마이그레이션이 적용된 DB를 그대로 사용합니다.

## 백업 주의
JSON에는 데이터베이스 행, 앱 환경설정, 첨부파일 경로가 포함됩니다. 업로드한 이미지·PDF 원본 파일 바이트 자체는 JSON에 포함되지 않습니다.
