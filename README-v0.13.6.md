# TRIP:ON v0.13.6

- 예정/실제 연결 표시 방식을 실제로 세 가지 동작으로 분리
  - 예정 중심: 예정 카드만 시간축에 표시
  - 실제 중심: 실제 카드만 실제 시간으로 시간축에 표시
  - 둘 다: 두 카드 모두 표시
- 연결 표시 방식 선택 UI를 작은 세그먼트 컨트롤로 축소
- 방문 묶음 N곳 컨트롤을 제목 옆에서 아래 보조 영역으로 이동하고 축소
- 방문 묶음 제목을 최대 2줄 표시, 펼친 목록과 접기 UI 축소
- 이동 일정의 시간축 마커를 원형 대신 다이아몬드 형태로 구분
- 바우처/문서를 2열 정사각형 갤러리 썸네일 + 아래 제목으로 표시
- 숙소 예약에서 체크인 일정 / 체크아웃 일정을 각각 선택적으로 연결
- 기존 v0.13.5의 참고링크, PWA, 첨부파일 표시 이름, 체크인/체크아웃 날짜/시간 구조 유지

추가 DB 마이그레이션 없음 (v0.13.5 마이그레이션 적용 상태 기준).
