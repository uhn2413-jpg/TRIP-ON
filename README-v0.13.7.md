# TRIP:ON v0.13.7

Responsive layout pass for tablets and laptops.

- Mobile layout remains the default.
- Tablet breakpoint begins at 720 CSS px and is tuned around Galaxy Tab S7+ class screens (12.4-inch, 16:10).
- Wide tablet/laptop breakpoint begins at 1100 CSS px.
- Trip schedule remains intentionally narrower for timeline readability.
- Prep, records, expenses, scraps, and trip lists make better use of wider screens with multi-column grids.
- Bottom sheets are capped to readable widths rather than stretching across the tablet display.
- No Supabase migration is required.
